# Faith Clinic Foundation — Website V2

A lightweight, responsive, static NGO website ready for GitHub and Netlify.

## Included
- Professional responsive homepage
- Education, healthcare, skills and youth empowerment programs
- Community impact stories
- Gallery using the supplied Foundation event photograph
- Partnership, volunteer and donation calls-to-action
- Supplied Faith Clinic Foundation logo
- SEO metadata, robots.txt and sitemap.xml
- Netlify configuration
- No build step required

## Important
The website intentionally does **not** invent bank account details. The website includes three official online donation destinations:
- https://pay.squadco.com/LGGMCM
- https://pay.squadco.com/5WAEJD
- https://pay.squadco.com/DNRK9E

When the Foundation confirms official NGN/USD bank details, they can be added to the donation section.

## Local preview
Open `index.html` directly, or use VS Code Live Server.

## Netlify
Deploy the project folder or ZIP. Because this is a static site, the publish directory is the project root and no build command is required.

## Next content updates
Replace/add verified impact numbers, project dates, beneficiary stories, social media links, and additional gallery photos as they become available.


## Multi-page navigation
The website uses separate HTML pages. Home, About, Programs, Impact, Gallery, Partnerships, Get Involved, Blog, Contact and Donate are linked through the shared navigation and footer. No build command is required for Netlify.
