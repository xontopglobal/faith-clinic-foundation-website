# Faith Clinic Foundation International Website

Updated React/Vite website for Faith Clinic Foundation International.

## Latest update
- Added a professionally rewritten **Story Behind Faith Clinic Foundation** to the About page.
- Added founder journey, founding vision, mission, values and impact narrative.
- Added new visual story panels for education and volunteering.
- Added new page backgrounds using the supplied community and campaign images.
- Added responsive styling for story sections and visual message panels.
- Donation access remains available site-wide through the global donation banner and navigation.
- Quickteller donation link: https://business.quickteller.com/link/pay/FaithClyHpM1

## Main routes
- `/` Home
- `/about` About & Story
- `/programs` Programs
- `/what-we-do` What We Do
- `/our-work` Our Work
- `/gallery` Gallery
- `/get-involved` Get Involved
- `/donate` Donate
- `/contact` Contact
- `/team` Board & Team

## Build locally
```bash
npm install
npm run build
npm run dev
```

The project uses React, Vite, React Router and Lucide icons.
